

Um jogo em 2D desenvolvido em Java para a APS (Atividade Prática Supervisionada). O objetivo do projeto é aliar conceitos avançados de Programação Orientada a Objetos (POO) com a conscientização ecológica e sustentável.


Sobre o Jogo

O jogador explora um mapa de $50 \times 50$ blocos em busca de conhecimento. Espalhados pelo cenário, existem **10 NPCs**, cada um fornecendo uma dica ou informação crucial sobre sustentabilidade, reciclagem e preservação ambiental. 
Após coletar as informações, o jogador deve enfrentar o **ECO-BOSS** no quadrante superior do mapa. O combate final consiste em um **Quiz de 10 perguntas** baseado inteiramente nas dicas fornecidas pelos NPCs. Para vencer o Boss e salvar o planeta, o jogador precisará demonstrar que aprendeu todas as lições!



Movimentação Top-Down:** Controle do personagem pelo mapa usando o teclado.
Sistema de Estados de Jogo (State Pattern): Alternância fluida em tempo real entre o estados de exploração.
Sistema de Colisão Avançado
Gráficos Otimizados: Renderização em estilo Pixel Art.
